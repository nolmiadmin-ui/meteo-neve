# Meteo e neve sulle mie stazioni

Dashboard pubblica con meteo, neve e pericolo valanghe su 12 stazioni sciistiche (Campiglio, Canazei, Cervinia, Courmayeur, La Thuile, Livigno, Monterosa Ski, Pila, Zermatt), aggiornata ogni mattina.

- Meteo: media di 6 modelli (ECMWF, ICON, AROME, ICON-2I, UKMO, GFS) da Open-Meteo.
- Storico: rianalisi ERA5 (Open-Meteo), stagioni 2016-17 → 2025-26.
- Valanghe: bollettini AINEVA/EAWS e SLF letti da valanghe.report.

I dati sono nella cartella `data/`.
